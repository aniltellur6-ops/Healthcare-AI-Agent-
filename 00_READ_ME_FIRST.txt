## 📞 IF YOU GET STUCK

| Issue | Solution |
|-------|----------|
| `pip: command not found` | Install Python from python.org |
| `streamlit: not found` | Run `pip install -r requirements.txt` |
| `ModuleNotFoundError` | Ensure virtual env activated or pip install again |
| App won't start | Check port 8501 isn't in use |
| Database issues | Delete data/health.db and restart |
| AI not working | Add OPENAI_API_KEY to .env file |
